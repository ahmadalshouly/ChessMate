# Piece sets

Source artwork for the piece sets players can pick in **Settings > Board > Pieces**.
Every set here is licensed for commercial use. The app ships PNGs rendered from these
SVGs (`apps/app/assets/pieces`); rebuild them with `node apps/app/art/build-pieces.mjs`
after adding or changing a set (needs Playwright with Chromium).

The app shows these credits under **Settings > Board > Piece artwork credits**
(`src/features/board/pieceSets.ts`). Keep both lists in sync.

## Adding a set

1. Check the licence allows commercial use (no "NC" Creative Commons licences, no GPL/AGPL
   artwork, no "personal use" freeware).
2. Add `art/pieces/<id>/` with `wK.svg … bP.svg` (w/b + K Q R B N P) and the licence file.
3. Add the id to `PIECE_SETS` in `packages/core/src/profile.ts` and its credits to
   `PIECE_SET_INFO` in `apps/app/src/features/board/pieceSets.ts`.
4. Run `node apps/app/art/build-pieces.mjs` and commit the PNGs and `pieceImages.ts`.
