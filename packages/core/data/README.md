# Opening data

`a.tsv` … `e.tsv` are copied unchanged from https://github.com/lichess-org/chess-openings.
That data set is a collection of facts in the public domain, released under the
CC0 Public Domain Dedication. No Lichess code is used.

Regenerate `src/openings-data.ts` with `node scripts/build-openings.mjs`.
